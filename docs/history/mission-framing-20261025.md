# 2026-10-25 八關固定取景調整

基準版本：`8a74bce`；本次提交清單於文末。警察隊由使用者指定另行重新設計，本次沒有修改。
設計來源、上下左右取捨及前後投影比例見[九關取景檢視](../mission-framing-audit.md)。

## 範圍與契約

八關固定相機收緊；消防／交通縮短可見手動車程，碼頭／山路調整手動端點。
修路、房屋與碼頭延伸底層地面並沿原視線後退固定相機，避免直向近裁切與地面邊界。
E01～E09、資源所有權、生命週期、存檔欄位與版本、取消與失敗處理均無變更。
消防及交通的顯示／輸入正反映射保留目前版本的絕對車程；碼頭及山路沿用原有比例進度。

## 自動檢查

- `npm run check` 通過：682 個測試、TypeScript 檢查、Vite 正式建置與 PWA 產物生成。
- 新增八個逐關 `domain/framing.test.ts`，由既有 `npm test` glob 自動納入；共用 `tests/helpers/framing.ts` 讀取實際 Three.js 模型與相機，只替換 WebGL／DOM 邊界。
- 畫布為 1280 × 800、390 × 844、1024 × 768、844 × 390。檢查完整模型包圍範圍、2% 邊緣餘裕及遊玩進度不移動／旋轉相機。
- 修路含兩側工地、三種破損、挖臂高點、車斗及壓路端點；房屋含兩側、三種屋頂、送貨、空鉤與各層吊裝；消防含進場、反向輸入映射、救援籃高點與擔架。
- 交通含兩種拖吊車、兩個方向與被拖車完整組合，手動行程 11 個取樣點及自動整車離場；碼頭含裝／卸、兩側、船車手動行程 11 點與吊貨。
- 山路含兩側、兩種碎石配置、鏟裝路徑、清運／清掃端點與碎屑覆蓋；轉運含兩側、兩種等候大型車與開門；清潔隊含兩側、兩種次序、兩種升桶與翻桶 11 點。
- 轉運及清潔隊既有動線投影檢查追加矮橫向尺寸。修路／房屋／消防的既有 Playwright 座標輔助同步新相機，保留供 CI 使用。

曾在使用者指定全部採內建瀏覽器前嘗試本機 Playwright，因缺少套件對應的 Chromium 而未執行到遊戲案例；沒有下載瀏覽器，也沒有把該次失敗算成通過。
後續全部本機瀏覽器驗證使用 Codex 內建瀏覽器。既有 Playwright 案例本次未成功執行，不能宣稱 CI 瀏覽器套件通過。

## 驗證限制

沒有從開場完整重玩全部八關或窮舉瀏覽器所有配置／順序；各階段透過既有開發入口抵達。
投影檢查以離散姿態與路徑取樣確認模型可見性，不能取代遮擋、HUD 或操作體感的完整人工檢查。
尺寸模擬不代表實體手機觸控；本次未重跑正式 preview、PWA 升級、HMR／隱藏頁面故障或全套手動失敗注入。
TypeScript／正式建置通過不等同上述瀏覽器案例已覆蓋。沿用現有 Vite 大 chunk 提醒，未擴大成本次 bundle 最佳化。
