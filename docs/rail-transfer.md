# 第十關：列車轉乘

2026-10-31 首版。關卡入口 `#rail-transfer`；沿用 Vite、TypeScript、Three.js、Effect 4.0.5 與 E01～E09。模型目錄見 [建模清單](model-catalog.md)，生命週期與測試範圍見 [Effect 指南](effect-usage.md)及[驗證指南](effect-verification.md)。

## 玩法與固定流程

每局四種列車、六位乘客，兩班送達、另兩班接走。所有車輛均有靠站、開門及出發操作，約十二次主要拖曳；乘客自動走動，不要求閱讀、逐人拖曳或分類。

1. 兩班來源列車從畫外沿各自軌道進入待命位置，停妥後同時顯示可選底圈。幼兒直接拖任一班靠站，決定第一組接車順序。
2. 到位後，用新手勢沿箭頭拉開近側滑門；三位乘客從實際門洞下車，沿月台、緩坡與中央大廳走向下一班候車區。走妥後自動關門，再拖空列車向外離站。
3. 第一班整車出框才開放另一班；兩班來源列車離場後，目的地列車再從畫外進入各自待命位。六位乘客依列車圖像及位置自動等候，每班接三人。
4. 幼兒獨立選擇第二組接車順序。靠站、拉門、乘客自動上車、關門，再拖車出發。
5. 最後一班完整離場後，站務員揮手、紙花與重玩／選關自然接續；沒有額外確認。

一般拖曳放手或取消即暫停，保留部分行駛／開門。初次拖曳保留 8 px 防誤觸；中斷後依剩餘距離降低啟動門檻，短於 8 px 也能接續。已到終點的中斷仍留在原步驟，新手勢放手即可接續；取消不提交。行駛指向終點停留 0.4 秒，或在有效終點放手，系統接手完成停妥／離站；後者仍逐幀前進，不瞬移。自動接手後舊指標不能控制下一步。

## 固定視角、場地與四邊取景

四條獨立端點軌道分成前後兩排，後排為高鐵／區間車，前排為捷運／輕軌。中央大廳接通四個近側月台，短緩坡配合各車入口高度。人物全程走步行區，只有實際登車時跨入門洞；沒有平交道或跨軌步行。

列車採高鐵八節、區間車六節、捷運六節、低地板輕軌雙節的雙端編組，朝中央靠站，換端向外離站。長列車以靠近中央大廳的首節為停靠與操作基準，其餘車廂及月台向外延伸出框。實際止衝擋、車頭、車門、候車區與長椅分離。左右鏡射只換場地位置，列車近側門仍朝玩家，整局保持同一正交相機位置／朝向。高鐵以長而低、逐段收窄的鼻端與乾淨車頂辨識；區間車為較高的銀色方正車體、窄門與黃色駕駛端側面；捷運有深色包覆前窗、每節兩組寬門及雙車頂冷氣箱；輕軌為較短、較低的雙節車身、大窗與深色鉸接。

| 邊緣 | 全流程必要內容 | 取捨與最不利階段 |
| --- | --- | --- |
| 上 | 後排首節車頭、開門、下車及月台 | 站房降低、樹木退至兩端；裁掉遠景，不為站房擴大取景。後排高鐵待命／集電弓／開門均列入模型投影。 |
| 下 | 前排操作車廂、近側門、候車及上車 | 刪去前方站外道路與廣場；保留完整手勢、小手及下方 HUD 間距，檢查前排出發終點。 |
| 左 | 左側首節與完整操作範圍 | 保留原本短距離手動行程，其餘車廂及月台刻意裁在左邊界外；終點後以首端錨點與完整模型核對自動離場，不要求追車。 |
| 右 | 右側首節與鏡射後的所有操作 | 長列車與月台同樣向右延伸；首節鼻端、滑門與提示完整可見，輕軌仍保留雙節全車；兩側車門均向中央示範，避免手勢指向畫外。 |

依 2026-11-01 使用者要求，列車轉乘明確採用「長編組尾端可出框」的取景例外；可操作首節、實際車門、全部上下車路徑與小手完整保留，進場起點及離場交接仍核對整個編組。固定相機位置、朝向與 17.8 最小高度／24.9 最小寬度不變，不為了裝進八節車而拉遠。

高鐵鼻端由 0.8 延長為 2.35 世界單位，並同時降低、收窄尖端；車頭與輪子位置以純 `domain/formation.ts` 與真實模型共用。舊首版短編組的整車 303×123／117×48／96×39 px 數值保留為 2026-10-31 的歷史量測，不能套用於目前長編組。新模型的同畫布首節／鼻端投影與操作驗證記於下方本次紀錄。

## 本局變化、選擇與續玩

- 四種列車任取兩班先送達，其餘兩班接走，共六組：`city` 高鐵＋區間、`outbound` 捷運＋輕軌、`hsr-metro` 高鐵＋捷運、`hsr-tram` 高鐵＋輕軌、`regional-metro` 區間＋捷運、`regional-tram` 區間＋輕軌。入場組合與左右配置獨立抽選，新局不重複上一組；每局皆四車六人，兩個組內仍各自由幼兒決定先後。
- 兩套完整左右配置獨立抽選；四組列車配色新局不重複上一組。成人／孩子沿用既有人物及背包外觀，服裝造型保留既有模型。
- 兩組列車各自的先後順序由幼兒選，不由隨機或提示決定。所有合法選項同時顯示相同底圈與車名，一次只有一隻小手，完成整個 2.4 秒示範後才換下一班。
- 抓車立即停止示範；無進度的點按／取消恢復選擇，有進度則保留該班。減少動態模式保持兩班可選，停止示範輪替與手指位移。提示時鐘屬 connection，不存進度。
- 完整 version 1 保存 round、已離場順序、目前列車、部分行駛／開門、接手與自動時鐘。人物與車輛姿態由這份狀態連續推導，沒有獨立隨機位置。
- reload／HMR 保留同局、部分工作與自動接手，清除舊 pointer、未提交停留與暫時拖曳目標。已完成快照不重播離站。只接受完整目前版本，舊版／缺欄位／矛盾狀態開新局，不做遷移。
- 正式進度 key `town-crew:play:v1:rail-transfer`，開發 key `town-crew:rail:dev:v1:<query>`，上一局 `town-crew:rail:last-round:v1`；上一局記憶體與進度分離，儲存拒絕不阻擋新局。

| 分類 | 來源與範圍 |

| 新增 | `rail-transfer/vehicles.ts` 八／六／六／雙節的軌道編組、鋼輪轉向架、連結部、座椅、門洞、雙片滑門與雙端燈。高鐵長鼻與低尖端，區間車黃面方頭、捷運雙寬門／冷氣箱，輕軌低地板、鉸接與集電弓；不是公車換色。 |
| 新增場地 | `rail-transfer/scene.ts` 的分離軌道、枕木、止衝擋、月台、緩坡與中央大廳；車／人物／提示與投影共用 `domain/station.ts`，各車型的首節、門位置與編組長度共用 `domain/formation.ts`。SVG 選關與四車圖示為 `app/rail-art.ts`。 |

`domain/` 僅普通 TypeScript，沒有 DOM、Three.js 或 Effect 值。`scene/session/persistence/services/startup` 沿用既有任務分層與靜態 lazy 分支；沒有新增通用關卡引擎、遠端服務或常駐工作。

任務 scope 擁有 renderer、scene、陰影、材質及 audio Layer；connection 擁有 AbortController、pointer、小手、同步最後存檔及 DOM 事件。取得資源時立即登記獨立 finalizer，部分初始化失敗仍回收已取得的資源；取消先停止 frame／autosave，再取消輸入、同步保存，清理提示與監聽，等待 audio close 後釋放場景。正常取消不當成錯誤；frame／非預期快照複製缺陷會結束該任務並經既有錯誤畫面回選關。

音效只有可選短提示音，手勢內解鎖，解鎖失敗仍可操作且後續可重試；沒有持續列車聲或額外音效節點所有權。定期存檔沿用受監督 700 ms worker，隱藏時跳過定期寫入，pagehide／hidden 事件與最後保存保持同步。
